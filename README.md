
# 🎮 CodeQuest – Programming Adventure Game

CodeQuest is an interactive programming game designed to help students improve their coding knowledge and problem-solving skills through fun and engaging challenges.

## 🚀 Features

- **Code Quiz:** Test programming knowledge through multiple-choice questions.
- **Bug Hunter:** Identify and fix errors in code.
- **Output Master:** Predict the output of programming code.
- **Missing Code:** Complete incomplete code snippets.
- Multiple difficulty levels: Easy, Medium, and Hard.
- Timer-based challenges.
- Score tracking and quiz results.
- User authentication.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend Setup

Open another terminal:

```bash
cd backend
npm install
npm start
```

### 4. Database Setup

- Install and open MySQL.
- Create the CodeQuest database.
- Import the project SQL schema and question data.
- Configure your database credentials in the backend `.env` file.
